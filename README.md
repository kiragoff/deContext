# deContext

Designed to visualize differential expression in a genomic context, because sometimes looking at a hit table doesn't show you the big picture. A modular, robust R toolkit for extracting, parsing, and visualizing genomic neighborhood dynamics alongside multi-timepoint differential expression data (e.g., time-course RNA-seq).

Designed to be fully agnostic to upstream differential expression tools and compatible with standard GenBank (`.gbff` / `.gbk`) files.

---

## Features

- **Differential Expression Visualization:** Colour-codes genes based on log2 fold change and marks genes meeting your significance threshold.
- **Flexible Time-Point Parsing:** Dynamically detects any number of time points using standard `[metric]_[timepoint]` column naming.
- **Integrated Operon Mapping:** If operon data is not already available, the pipeline auto-detects probable operons on the fly using strand orientation and intergenic distance gaps. 
- **Multiple Query Modes:** Query by gene, predefined operon, or use a query gene to predict the operon.
- **Automated Output:** Uses filter parameters to dynamically name and automatically save high-resolution PNG files.

---

## Input Data Requirements

### 1. GenBank File (`.gbff` / `.gbk`)
* Standard reference files or Bakta/Prokka output.

### 2. Differential Expression CSV
* **Agnostic:** Output generated by your favorite tool (DESeq2, edgeR, limma, etc.).
* **Required Column:** `locus_tag` (to match features to the GenBank file).
* **Time-Point Columns:** Must follow the format `[metric]_[timepoint]` (e.g., `log2FC_0h`, `log2FC_2h`, `padj_0h`). 
  * *Accepted Metric Naming Patterns:* 
    * Fold Change: `lfc`, `log2fc`, `fold`, `fc`
    * Significance: `padj`, `p_adj`, `qval`, `pval`
    * Time Format: Numbers or hours (e.g., `_0`, `_0h`, `_12h`)
* **Columns for Annotation:**
    * Gene: Short-form gene name
    * Product: A longer descriptor for summary tables
    * Operon: If using the pre-calculated 'operon' or 'gene' modes

---

## Visualization Styles & Options

`plot_neighbourhood()` supports multiple rendering layouts and customization flags via its arguments:

* **`style = "none"`**: Standard gene arrows colored by expression, with significance stars (`*`). 
* **`style = "above"`** *(Default)*: Automatically places clean, non-overlapping external gene labels above the top timepoint track using `ggrepel`.
* **`style = "table"`**: Combines the genomic neighborhood plot with a companion metadata summary table showing `locus_tag`, `operon_id`, and product descriptions stacked underneath.
* **`clean_short_genes = FALSE`**: Embeds gene names directly inside the arrows rather than utilizing external labels with internal significance markers.
* **`colour_limits = c(-n, n)`**: Lets you set upper and lower bounds on the colour scale, essential for visually comparing multiple output plots.
* **`custom_palette = c("navy", "lightgrey", "darkorange")`**: Lets you define your own custom colour scale, with low, 0, and high colour points.

## Quick Start / Example Usage

See `analysis_notebook.Rmd` for a complete, interactive walkthrough. 

```r
# Ensure required packages are installed
# install.packages(c("tidyverse", "ggrepel", "gridExtra", "cowplot"))
# devtools::install_github("wilkeslab/gggenes") # or CRAN equivalent

library(tidyverse)
library(gggenes)
library(ggrepel)
library(gridExtra)
library(cowplot)

# Source core modules
source("R/parse_neighbourhood.R")
source("R/extract_neighbourhood.R")
source("R/plot_neighbourhood.R")

# Ingest data
genomic_df <- parse_gbff(
  gbff_path = "your/path/organism.gbff", 
  de_csv_path = "your/path/differential_output.csv"
)

# Set query and filter parameters
filtered_data <- parse_neighbourhood(
  master_data = genomic_df, 
  query_type = "operon", 
  query_values = c("2038"), 
  flank_operons = 2
)

# Plot and automatically save
plot_neighbourhood(
  filtered_data = filtered_data, 
  style = "above", 
  deseq_path = "git-ignore/annotated_operons_clusters_stats.csv", 
  output_dir = "git-ignore/operon-results"
)
```
